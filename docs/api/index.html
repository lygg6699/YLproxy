YLproxy API Documentation

Version: 0.2.0.0

REST API for managing proxy configurations, testing connectivity, and controlling proxy lifecycle.

Health

GET/api/health
Service health check endpoint

Proxies

GET/api/proxies
Retrieve all proxy entries
GET/api/proxies/{id}
Retrieve a single proxy by ID
POST/api/proxies
Create a new proxy entry
DELETE/api/proxies/{id}
Delete a proxy entry by ID
POST/api/proxies/{id}/test
Test proxy connectivity
POST/api/proxies/{id}/start
Start a proxy
POST/api/proxies/{id}/stop
Stop a proxy

Stats

GET/api/stats
Get dashboard statistics
