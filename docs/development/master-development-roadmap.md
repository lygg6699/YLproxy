## 📤 本地与云空间同步机制

### 同步策略
1. **原子提交原则：** 每个功能点完成后立即提交，避免大量变更堆积
2. **提交信息规范：** 使用 `[Phase X.Y] 功能描述` 格式
3. **分支策略：**
   - `main`：稳定版本，仅合并经过 CI 验证的代码
   - `develop`：开发分支，日常开发在此分支
   - `feature/xxx`：功能分支，大功能独立开发

### 同步流程
```
本地开发 → 单元测试 → Commit → Push → 触发 CI → CI 验证 → 合并到 main
```

### 冲突解决
- 每次本地工作前先 `git pull`
- 如有冲突，优先解决冲突后再继续开发
- 重大变更前创建功能分支
